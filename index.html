SELAMAT DATANG DI OPTIRDPU

Maksimalkan Return Portofolio RDPU Anda

Alat bantu kuantitatif berbasis algoritma Dynamic Programming (0/1 Knapsack) untuk investor ritel. Kami secara otomatis merekomendasikan kombinasi produk Reksa Dana Pasar Uang terbaik untuk mencapai imbal hasil maksimal, tanpa melebihi batas modal yang Anda miliki.

Mesin Optimasi RDPU

Dynamic Programming membantu memilih kombinasi produk RDPU terbaik berdasarkan modal, minimum investasi, dan return.

CORE ENGINE

Teknologi Komputasi Tingkat Lanjut

OptiRDPU dirancang dengan performa komputasi tinggi menggunakan Bun & Hono di sisi backend untuk latensi super rendah, melayani perhitungan matematis kompleks secara instan.

  • Mesin 0/1 Knapsack (Array 1D)

    Menggunakan pendekatan bottom-up dengan rolling array optimization untuk memaksimalkan return tanpa mengorbankan memori server.

  • Hybrid Greedy-Filtered Failsafe

    Otomatis menyaring produk (Top K) berdasarkan rasio profit-to-weight ketika dataset membengkak, menjaga sistem tetap responsif.

  • Integrasi Data RDPU Dinamis

    Data batas minimal investasi dan historis return 1 tahun ditarik dan disesuaikan dari platform kredibel agar hasil komputasi akurat.

FAQ OptiRDPU

Pertanyaan umum mengenai RDPU, Knapsack, sumber data, dan cara kerja sistem.

RDPU adalah jenis reksa dana yang menginvestasikan dananya khusus pada instrumen pasar uang domestik seperti deposito berjangka dan obligasi di bawah 1 tahun. Risikonya sangat rendah dengan return yang stabil, cocok untuk investor pemula.

Aplikasi ini memperlakukan modal Anda sebagai "Kapasitas Ransel" (Capacity), batas minimum beli produk sebagai "Bobot" (Weight), dan ekspektasi return sebagai "Nilai" (Value). Mesin kami menghitung kombinasi pasti agar nilai return maksimal tanpa ransel (modal) jebol.

Pada rentang modal ini (modal kritis), variasi minimum pembelian antar produk (seperti Rp10.000 vs Rp100.000) sangat mempengaruhi fleksibilitas alokasi. Algoritma 0/1 Knapsack terbukti bekerja paling efektif pada batasan ketat seperti ini.

Tidak. Sistem kami murni bertindak sebagai alat bantu kuantitatif (kalkulator) dan tidak terkoneksi dengan perbankan atau mendepositkan uang Anda. Anda mengeksekusi transaksinya secara mandiri di platform sekuritas favorit Anda.

Data metrik seperti batas minimal investasi dan historikal return 1 tahun kami integrasikan dan diperbarui secara berkala dari platform reksa dana kredibel di Indonesia (seperti Bareksa) untuk memastikan akurasi perhitungan.

Pendekatan equal-weight seringkali mengabaikan batasan minimum pembelian dan potensi return produk superior. Knapsack memberikan pembuktian matematis bahwa membobotkan alokasi berdasarkan rasio produk akan menghasilkan Total Return yang lebih tinggi di akhir periode.
